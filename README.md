# Power BI Sales Dashboard – Experiment 2

## Objective
Create a basic interactive sales dashboard using Power BI.

## Tools Used
- Power BI Desktop
- Microsoft Excel

## Dashboard Features
- Total Sales KPI
- Total Orders KPI
- Average Order Value
- Revenue by Month
- Revenue by Region
- Revenue by Category
- Quantity by Product
- Sales Details Table
- Region Slicer

## Output
Interactive Power BI Sales Dashboard created using a dummy sales dataset.

## Files
- PBIX: Power BI dashboard project
- XLSX: Dataset
- PNG: Dashboard screenshot
